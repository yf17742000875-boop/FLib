# 6.2-6.4 图像卷积、填充与步幅、多输入多输出通道

## 一句话总结

**大白话**：[[卷积]]核就是个小窗口在图上滑动算加权和。填充（padding）= 在边上补一圈零，免得越滑越小、边角信息丢失；步幅（stride）= 一次跨几格，跨得大图就缩得快（下采样）。每个输出通道是一个独立的滤波器；1×1 卷积不看空间、只在通道之间做混合（升降维）。

**严谨说法**：卷积层用互相关计算特征图；填充 (padding) 控制输出尺寸、步幅 (stride) 控制下采样；多输入通道按通道求和，多输出通道即多个独立滤波器，1×1 卷积用于通道融合。

---

## 1. 卷积 vs 互相关：工程与数学的"文字游戏"

### 数学定义区别

| | 数学卷积 | 互相关（深度学习"卷积"） |
|---|---|---|
| 操作 | 先翻转核（180°），再滑窗相乘 | 不翻转，直接滑窗相乘 |
| 公式 | \((f*g)(i,j)=\sum_a\sum_b f(a,b)\,g(i-a,j-b)\) | \((f\star g)(i,j)=\sum_a\sum_b f(a,b)\,g(i+a,j+b)\) |

### 为什么深度学习不区分？

卷积核的权重是**从数据中学习的**。如果底层执行互相关，网络会学出一组权重 K；如果改执行严格卷积，网络只需把权重自动调整为翻转后的 K' 即可达到完全相同输出。**翻转操作对最终模型效果零影响。**

### 工程惯例

为了节省计算资源（翻转需要额外计算），主流框架（PyTorch、TensorFlow）底层实际执行的都是**互相关运算**，但在学术和文档中统一称为"卷积运算"。

### 互相关运算代码

```python
def corr2d(X, K):
    """二维互相关运算 — 不翻转核，这才是深度学习的"卷积" """
    h, w = K.shape
    Y = torch.zeros((X.shape[0] - h + 1, X.shape[1] - w + 1))
    for i in range(Y.shape[0]):
        for j in range(Y.shape[1]):
            Y[i, j] = (X[i:i + h, j:j + w] * K).sum()
    return Y
```

**示例**：3×3 输入 × 2×2 核 → 2×2 输出

```
输入 X:              核 K:          输出 Y:
[0  1  2]           [0  1]         [19  25]
[3  4  5]    ⋆      [2  3]    =    [37  43]
[6  7  8]

计算: 0×0+1×1+3×2+4×3=19, 1×0+2×1+4×2+5×3=25, ...
```

> **速记**：工程上"卷积"其实是"互相关"，反正权重自适应不用管翻转。

## 2. 特征映射与感受野

| 概念 | 定义 | 通俗理解 |
|------|------|----------|
| **特征映射**（Feature Map） | 卷积层输出的结果矩阵 | 原始输入经过该层卷积核"提取特征"后的新版本图片 |
| **感受野**（Receptive Field） | 某层输出元素在原始输入图上能"看到"或影响的区域大小 | 该输出点往回追溯，能覆盖原始图片的像素范围 |

---

## 3. 深度（层数）与感受野的扩展规律

### 逐层传递

- **浅层**：特征直接受原始图像影响（感受野小），看到具体细节（边缘、纹理）
- **深层**：特征受浅层特征影响。由于浅层已包含局部信息，深层叠加后**视野天然扩大**
- **最深层**：融合全局判断整体类别（猫、车）

### 叠加效应

> 两层 3×3 卷积堆叠，其顶层感受野等效于一层 5×5 卷积。

```
第1层 3×3 → 每个输出看 3×3 输入区域
第2层 3×3 → 每个输出看第1层的 3×3 区域 → 等价于看输入的 5×5 区域
```

**深层"看到更宽"的两层含义**：

| 维度 | 浅层 | 深层 |
|------|------|------|
| 空间覆盖 | 窄（2×2、3×3） | 广（可覆盖全图） |
| 语义层次 | 具体（边缘、纹理） | 抽象（五官、部件）→ 全局（猫、车） |

---

## 4. 为什么堆叠小卷积核而不是直接用大卷积核？

两层 3×3 获得与一层 5×5 同等视野，但优势明显：

| 对比维度 | 两层 3×3 | 一层 5×5 |
|----------|----------|----------|
| 参数量 | 2 × 3² = 18 | 5² = 25 |
| 非线性 | 中间多 1 次 ReLU（更强） | 只有 1 次 |
| 计算量 | 更轻量 | 更重 |

> **总结**：堆叠小核 = 同等视野 + 参数更少 + 非线性更强。这就是 VGG 等经典网络的设计哲学。

---

## 5. 图像中目标的边缘检测（实战案例）

卷积核可以手动设计来检测特定模式。例如 `[1, -1]` 检测**垂直边缘**：

```python
X = torch.ones((6, 8))       # 6×8 图片
X[:, 2:6] = 0                # 中间 4 列为黑色（0），其余为白色（1）
# 形成两处边缘：列1→2（白→黑），列5→6（黑→白）

K = torch.tensor([[1.0, -1.0]])     # 1×2 水平差分核
Y = corr2d(X, K)
# 输出: 边缘处为 1（白→黑）或 -1（黑→白），平坦处为 0
```

**核的设计逻辑**：
- `[1, -1]`：水平相邻差值 → 检测**垂直**边缘
- `[[1], [-1]]`：垂直相邻差值 → 检测**水平**边缘

> 更复杂的核无法手工设计——解决方法是**让网络自己学**。

## 6. 学习卷积核（从数据中自动学）

```python
conv2d = nn.Conv2d(1, 1, kernel_size=(1, 2), bias=False)

for i in range(10):
    Y_hat = conv2d(X)
    l = (Y_hat - Y) ** 2        # 平方误差
    conv2d.zero_grad()
    l.sum().backward()          # 反向传播计算梯度
    conv2d.weight.data[:] -= lr * conv2d.weight.grad  # 梯度下降更新
```

训练后卷积核权重会逼近 `[1, -1]`，证明网络能从数据中自动学到边缘检测器——这就是 CNN 强大的根源。

## 7. 输出尺寸公式

输入 \(n_h \times n_w\)，核 \(k_h \times k_w\)，填充 \(p_h, p_w\)，步幅 \(s_h, s_w\)：

$$\left\lfloor\frac{n_h - k_h + 2p_h + s_h}{s_h}\right\rfloor \times \left\lfloor\frac{n_w - k_w + 2p_w + s_w}{s_w}\right\rfloor$$

常见简化版：

| 场景 | 公式 | 示例 (32×32, k=3) |
|------|------|-------------------|
| 无填充，步幅 1 | \((n - k + 1)\) | 30×30 |
| 无填充，步幅 s | \(\lfloor (n-k)/s \rfloor + 1\) | s=2 → 15×15 |
| 保持尺寸 | padding = (k-1)/2（奇数核） | p=1 → 32×32 |

---

## 8. 填充（Padding）与步幅（Stride）

| 参数 | 作用 | 取值 | 效果 |
|------|------|------|------|
| **padding** | 在图像边缘补值（通常是 0），防止输出缩小、让边界像素能参与卷积 | 常用 `(k-1)/2` | 保持空间尺寸不变 |
| **stride** | 卷积核每次滑动的步长 | 默认 1 | stride=2 输出尺寸减半（下采样） |

### 常用配置

```python
# 保持尺寸不变
nn.Conv2d(in_c, out_c, 3, padding=1)     # 3×3 核 → padding=1

# 减半下采样
nn.Conv2d(in_c, out_c, 3, padding=1, stride=2)
```

## 9. 多输入多输出通道

### 多输入通道（如 RGB）

- 输入形状：\((B, c_i, H, W)\)，卷积核形状：\((c_o, c_i, k_h, k_w)\)
- 每个输出通道对应一个 \(c_i \times k_h \times k_w\) 的滤波器
- 对 \(c_i\) 个输入通道分别卷积后**求和**，得到单张特征图
- \(c_o\) 个滤波器 → \(c_o\) 张特征图（\(c_o\) 个输出通道）

### 多输出通道

每个输出通道是一个**独立的滤波器**，检测不同特征：
- 浅层：通道可能分别检测水平边缘、垂直边缘、纹理等
- 深层：通道可能检测眼睛、鼻子等更抽象的模式

### 权重形状速记

```python
conv = nn.Conv2d(in_channels=3, out_channels=64, kernel_size=3)
print(conv.weight.shape)  # torch.Size([64, 3, 3, 3])
#                                        ↑   ↑  ↑  ↑
#                                       c_o c_i kh kw
```

> **铁律**：`(out_channels, in_channels, kernel_h, kernel_w)`

## 10. 1×1 卷积

不看空间，只在通道维度做线性组合：

$$
[H]_{i,j,d} = \sum_c [V]_{0,0,c,d} \cdot [X]_{i,j,c}
$$

| 特性 | 说明 |
|------|------|
| 等价于 | 每个像素位置独立做 `in_c → out_c` 的全连接 |
| 空间尺寸 | 不变（kernel_size=1） |
| 主要用途 | 跨通道信息融合、升维/降维 |
| 经典应用 | ResNet 瓶颈块、GoogLeNet Inception |

---

## 输入输出形状

- 输入 `(B, c_i, H, W)` → 输出 `(B, c_o, H', W')`，`H'/W'` 由输出尺寸公式决定。

---

## 最小可运行代码

```python
import torch
from torch import nn

# 保持尺寸
conv = nn.Conv2d(3, 16, kernel_size=3, padding=1, stride=1)
X = torch.randn(2, 3, 32, 32)
print(conv(X).shape)        # (2, 16, 32, 32)

# 下采样
down = nn.Conv2d(16, 32, kernel_size=3, padding=1, stride=2)
print(down(conv(X)).shape)  # (2, 32, 16, 16)

# 1×1 卷积（通道变换）
conv1x1 = nn.Conv2d(32, 64, kernel_size=1)
print(conv1x1(down(conv(X))).shape)  # (2, 64, 16, 16)

# 手写互相关
def corr2d(X, K):
    h, w = K.shape
    Y = torch.zeros((X.shape[0] - h + 1, X.shape[1] - w + 1))
    for i in range(Y.shape[0]):
        for j in range(Y.shape[1]):
            Y[i, j] = (X[i:i + h, j:j + w] * K).sum()
    return Y

# 手写 Conv2D
class Conv2D(nn.Module):
    def __init__(self, kernel_size):
        super().__init__()
        self.weight = nn.Parameter(torch.rand(kernel_size))
        self.bias = nn.Parameter(torch.zeros(1))
    def forward(self, x):
        return corr2d(x, self.weight) + self.bias
```

## 易错点

- 算输出尺寸时漏掉步幅/填充导致维度对不上。
- 多通道权重形状记错：是 `(out, in, kh, kw)`。
- 误以为 1×1 卷积无用——它是跨通道信息融合与降维的利器。
- 混淆数学卷积（需翻转）与深度学习"卷积"（互相关，不翻转）。
- 误以为感受野只由核大小决定——层数堆叠才是扩大感受野的主要手段。

## 核心总结

| 问题 | 答案 |
|------|------|
| 深度学习的"卷积"实际是什么？ | 互相关（不翻转核），权重要靠学习，翻转与否无影响 |
| 特征映射是什么？ | 卷积层输出的结果矩阵，是特征提取后的"新图片" |
| 感受野是什么？ | 输出元素在输入上能"看到"的区域大小 |
| 如何扩大感受野？ | 堆叠层数（两层 3×3 = 一层 5×5） |
| 为什么堆叠小核优于大核？ | 参数更少 + 非线性更强 |
| padding 的作用？ | 控制输出尺寸，防止越卷越小，让边界像素充分参与 |
| stride 的作用？ | 控制下采样速率 |
| 1×1 卷积的作用？ | 跨通道线性组合（融合/升降维），不改变空间尺寸 |
| 多通道卷积核的形状？ | `(c_o, c_i, k_h, k_w)` |
| 卷积核可以手动设计吗？ | 简单模式可以（如边缘检测 [1,-1]），复杂模式靠学习 |

## 复习卡片

- Q: 保持输出尺寸的常用填充？
  A: 奇数核取 `padding=(k-1)/2`。
- Q: 多输出通道卷积权重形状？
  A: `(c_o, c_i, k_h, k_w)`。
- Q: 1×1 卷积的作用？
  A: 跨通道线性组合（融合/升降维），不改变空间尺寸。
- Q: 两层 3×3 堆叠的感受野等价于？
  A: 一层 5×5 卷积。
- Q: 深度学习"卷积"和数学卷积的区别？
  A: 数学卷积需翻转核，深度学习用互相关（不翻转），权重自适应无需区分。
- Q: 卷积的输出尺寸由什么决定？
  A: 输入尺寸 + 核大小 + 填充 + 步幅的几何关系。
