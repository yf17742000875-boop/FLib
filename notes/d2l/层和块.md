# 5.1 层和块 (Layers and Blocks)

## 一句话总结

**大白话**：在 PyTorch 里，不管是一个小零件（层）、一组零件（块）、还是整台机器（网络），都用同一种「积木」`nn.Module` 表示。想自己造积木，只要继承它、在 `__init__` 里登记有哪些子零件、在 `forward` 里写「数据怎么流过去」就行。

**严谨说法**：`nn.Module` 是 PyTorch 组织模型的统一抽象：单层、由层组成的块、整个网络都是 Module；自定义块只需继承它并实现 `__init__`（注册子模块）和 `forward`（定义前向）。

## 本节解决的问题

- `nn.Sequential` 内部如何工作？
- 如何自定义带控制流的前向计算？
- 块如何嵌套组合成复杂网络？

## 1. 层 (Layer) 的基本概念

### 1.1 什么是层？

**层是神经网络的最小可学习单元。** 它接收输入张量，做一次数学变换，输出新的张量。

```
输入 X  ──── [ 数学变换 + 参数 ] ────▶  输出 Y
  (N, d_in)                             (N, d_out)
```

层的数学本质（以全连接层为例）：

$$
Y = f(X \cdot W + b)
$$

- **`X`** — 输入矩阵，形状 `(N, d_in)`
- **`W`** — 权重矩阵，形状 `(d_in, d_out)`，**可学习参数**
- **`b`** — 偏置向量，形状 `(d_out,)`，**可学习参数**
- **`f`** — 激活函数（非线性），如 ReLU、Sigmoid

### 1.2 全连接层 (nn.Linear) 的数学原理

```python
import torch
from torch import nn

layer = nn.Linear(20, 256)     # 输入 20 维 → 输出 256 维
X = torch.rand(2, 20)          # batch=2, 特征=20
Y = layer(X)                   # (2, 256)
```

内部实际执行：

```
Y = X @ W^T + b

  X : (2, 20)      ← 2 个样本，每个 20 维
  W : (256, 20)    ← 权重矩阵（PyTorch 存转置形式）
  b : (256,)       ← 偏置
  Y : (2, 256)     ← 输出
```

**为什么叫"全连接"？** 输出层的每个神经元都和输入层的所有神经元相连。输入 20 维、输出 256 维，产生 `20 × 256 = 5120` 个权重连接。

**偏置 `b` 的作用**：如果没有 `b`，当 `X=0` 时输出必为 0，模型失去灵活性。`b` 让决策边界可以平移。

### 1.3 层的两大要素

| 要素                 | 含义            | 例子（Linear）                                   |
| ------------------ | ------------- | -------------------------------------------- |
| **参数（Parameters）** | 训练中被梯度下降更新的数据 | `layer.weight` (256×20), `layer.bias` (256,) |
| **前向传播（forward）**  | 给定输入，计算输出的规则  | `Y = X @ W^T + b`                            |

```python
print(layer.weight.shape)  # torch.Size([256, 20])  ← 可学习
print(layer.bias.shape)    # torch.Size([256])      ← 可学习
```

### 1.4 激活函数 —— 引入非线性

如果只有 `Linear` 层叠 `Linear` 层：

```
Y = (X @ W1 + b1) @ W2 + b2 = X @ (W1 @ W2) + (b1 @ W2 + b2)
                                    └── 还是一个大 W' ──┘
```

**多层线性 = 单层线性**，深度没有意义。激活函数打破这种线性，让网络能拟合任意复杂函数：

| 激活函数    | 公式                          | 特点                      |
| ------- | --------------------------- | ----------------------- |
| ReLU    | `max(0, x)`                 | 最常用，简单高效，缓解梯度消失         |
| Sigmoid | `1/(1+e^(-x))`              | 输出 (0,1)，适合二分类输出层       |
| Tanh    | `(e^x-e^(-x))/(e^x+e^(-x))` | 输出 (-1,1)，零中心           |
| GELU    | `x·Φ(x)`                    | Transformer 常用，平滑版 ReLU |

PyTorch 中两种用法：

```python
# 方式1：作为模块（有状态时用）
nn.ReLU()

# 方式2：作为函数（无参数时推荐，更轻量）
from torch.nn import functional as F
F.relu(X)
```

## 2. 块 (Block) 的定义与作用

### 2.1 什么是块？

**块是用 `nn.Module` 把多个层/子块打包在一起的容器。** 三个关键特性：

1. **本身也是 `nn.Module`**：块可以嵌套、可以像层一样被调用
2. **管理参数**：递归收集所有子层的参数，自动传给优化器
3. **定义前向传播**：决定数据如何在子层之间流动

### 2.2 最简单的块：`nn.Sequential`

```python
net = nn.Sequential(
    nn.Linear(20, 256),   # 全连接层
    nn.ReLU(),            # 激活
    nn.Linear(256, 10)    # 输出层
)
Y = net(X)   # 数据依次流过每一层
```

**局限性**：数据只能"串行流动"，不能有分支、跳跃连接、参数共享。

### 2.3 自定义块：`class MLP(nn.Module)`

当 `Sequential` 不够灵活时，自己写 `nn.Module` 子类：

```python
class MLP(nn.Module):
    def __init__(self):
        super().__init__()                          # ① 必须先调父类初始化
        self.hidden = nn.Linear(20, 256)             # ② 声明子层（__init__ 中）
        self.out = nn.Linear(256, 10)

    def forward(self, X):                            # ③ 定义数据流（forward 中）
        return self.out(F.relu(self.hidden(X)))
```

**两个必须遵守的规则**：

| 规则 | 位置 | 说明 |
|---|---|---|
| 层声明在 `__init__` | `self.hidden = nn.Linear(...)` | PyTorch 才能自动发现并管理参数 |
| 逻辑写在 `forward` | `def forward(self, X)` | 定义前向计算图，PyTorch 自动构建反向传播 |

## 3. `_modules` 字典 —— 模块注册的底层机制

`nn.Module` 能自动管理子模块，靠的是内部的 `self._modules` 这个 `OrderedDict`。

### 手写 MySequential 理解原理

```python
class MySequential(nn.Module):
    def __init__(self, *args):
        super().__init__()
        for idx, module in enumerate(args):
            self._modules[str(idx)] = module    # ← 关键：注册到 _modules

    def forward(self, X):
        for block in self._modules.values():    # OrderedDict 保证顺序
            X = block(X)
        return X

net = MySequential(nn.Linear(20, 256), nn.ReLU(), nn.Linear(256, 10))
net(X)
```

当执行 `self._modules["0"] = nn.Linear(20, 256)` 时：

- PyTorch 内部**自动遍历** `_modules` 字典
- 递归找到所有子模块的参数
- `net.parameters()` 返回所有叶节点层的参数
- `net.to(device)` 把子模块一起迁移到 GPU
- `net.train()` / `net.eval()` 递归切换所有子模块模式

**这就是 `nn.Sequential` 的简化版实现**，理解它就理解了模块注册机制。

## 4. FixedHiddenMLP —— 三个高级技巧

这是 5.1 节中最"有料"的示例，展示了超越普通 MLP 的灵活能力：

```python
class FixedHiddenMLP(nn.Module):
    def __init__(self):
        super().__init__()
        # 【技巧 1】常量参数：不参与训练
        self.rand_weight = torch.rand((20, 20), requires_grad=False)
        self.linear = nn.Linear(20, 20)

    def forward(self, X):
        X = self.linear(X)                              # 第一次调用 linear

        # 【技巧 1 续】常量张量参与计算但不更新
        X = F.relu(torch.mm(X, self.rand_weight) + 1)

        # 【技巧 2】参数共享：同一层被调用两次
        X = self.linear(X)                              # 第二次调用（共享参数！）

        # 【技巧 3】控制流：Python 原生 while 循环
        while X.abs().sum() > 1:
            X /= 2

        return X.sum()
```

| 技巧 | 为什么可行 | 注意事项 |
|---|---|---|
| **常量参数** `requires_grad=False` | forward 中任何 tensor 操作都能参与计算图；不要求梯度只是不更新 | 如需随模型迁移设备，用 `self.register_buffer()` |
| **参数共享** 同一层调两次 | 反向传播时，两次调用的梯度**自动累加**到同一组参数上 | 等价于"两个子任务共用一个层" |
| **控制流** `while` 循环 | PyTorch 是**动态计算图**，按实际执行的操作构建图，不关心 Python 语法 | 只要循环内是对 tensor 的操作，自动微分就有效 |

**深层含义**：`nn.Module` 的本质是一个**可微计算图的构建器**——`forward` 中可以做任意 Python 操作，PyTorch 都能自动求导。

## 5. 块的嵌套组合

### 层级结构示例

```python
class NestMLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(20, 64), nn.ReLU(),
                                 nn.Linear(64, 32), nn.ReLU())
        self.linear = nn.Linear(32, 16)

    def forward(self, X):
        return self.linear(self.net(X))

# 三种不同风格的块像乐高一样拼在一起
chimera = nn.Sequential(NestMLP(), nn.Linear(16, 20), FixedHiddenMLP())
chimera(X)
```

展开后的层级结构：

```
Sequential ("chimera")
 ├── NestMLP                          ← 自定义模块
 │    ├── net (Sequential)            ← 子块
 │    │    ├── Linear(20→64)          ← 层
 │    │    ├── ReLU()                 ← 层
 │    │    ├── Linear(64→32)          ← 层
 │    │    └── ReLU()                 ← 层
 │    └── Linear(32→16)               ← 层
 ├── Linear(16→20)                    ← 直接放一个层
 └── FixedHiddenMLP                   ← 带控制流的模块
      ├── rand_weight (常量)           ← 非参数
      └── Linear(20→20)               ← 层（被复用）
```

`net.parameters()` 会递归收集**所有叶子层**的参数，无论嵌套多深。

## 6. 工程化实战：Kaggle 房价预测中的块设计

文件：[4.10实战kaggle比赛预测房价.py](../../code/4.10实战kaggle比赛预测房价.py)

### 6.1 三件套架构

Kaggle 房价预测中的模型构建采用了工业界三件套：

```
Config (配置)
   │
   ▼
build_model() ──工厂函数──▶ HousePriceNet
                               │
                    ┌──────────┴──────────┐
                    │                     │
               backbone               head
          (nn.Sequential)       (nn.Linear → 1)
                    │
         ┌──────────┼──────────┐
         │          │          │
     MLPBlock   MLPBlock   ...     ← 按 Config 自动堆叠
```

### 6.2 可复用基础块：MLPBlock

```python
class MLPBlock(nn.Module):
    """标准前馈单元：Linear → (BN) → 激活 → (Dropout)"""
    def __init__(self, in_dim, out_dim, activation="relu",
                 use_batchnorm=True, dropout=0.0):
        super().__init__()
        layers = [nn.Linear(in_dim, out_dim)]
        if use_batchnorm:
            layers.append(nn.BatchNorm1d(out_dim))      # BN 在激活前
        layers.append(_ACTIVATIONS[activation]())
        if dropout > 0:
            layers.append(nn.Dropout(dropout))
        self.block = nn.Sequential(*layers)

    def forward(self, x):
        return self.block(x)
```

**设计要点**：
- BN 放在激活**前**：规范化线性输出，缓解内部协变量偏移（Internal Covariate Shift）
- Dropout 可选：本数据集特征是高维稀疏 one-hot，主要靠 weight_decay 正则
- 用注册表 `_ACTIVATIONS` 按字符串选择激活函数，不用到处 if-else

### 6.3 配置驱动的主模型：HousePriceNet

```python
class HousePriceNet(nn.Module):
    def __init__(self, input_dim, cfg: Config):
        super().__init__()
        blocks = []
        prev_dim = input_dim
        for h_dim in cfg.hidden_dims:           # 循环搭建：配置说几层就几层
            blocks.append(MLPBlock(prev_dim, h_dim, ...))
            prev_dim = h_dim
        self.backbone = nn.Sequential(*blocks)
        self.head = nn.Linear(prev_dim, 1)       # 回归头，不加激活/正则
        self.apply(self._init_weights)           # 递归初始化所有子模块
```

**精妙之处**：

| 设计 | 说明 |
|---|---|
| `hidden_dims = []` | 只剩 `head`，等价于**线性回归**，方便对比 |
| `hidden_dims = [64]` | 一个隐藏层 → 标准 MLP |
| `hidden_dims = [256, 128, 64]` | 三层深层网络，**代码一行不改** |
| 输出头不加激活 | 回归任务最后一层必须是纯线性，否则预测值被截断 |

**权重初始化**（`_init_weights`）：
- Linear → Kaiming(He) 初始化，适配 ReLU 系激活，保持各层方差稳定
- BatchNorm → weight=1, bias=0，初始时不改变分布

### 6.4 工厂函数：统一构建入口

```python
def build_model(input_dim: int, cfg: Config) -> nn.Module:
    """K 折评估和最终全量训练都调它，保证每次构建的模型完全一致。"""
    return HousePriceNet(input_dim, cfg)
```

### 6.5 Config 驱动的完整配置

```python
@dataclass
class Config:
    hidden_dims: List[int] = field(default_factory=lambda: [64])  # 结构
    dropout: float = 0.0
    use_batchnorm: bool = False
    activation: str = "relu"
    epochs: int = 200
    batch_size: int = 64
    lr: float = 1e-3
    weight_decay: float = 5e-3
    k_folds: int = 5
    seed: int = 42
```

**改结构不改代码**：`hidden_dims` 从 `[64]` 改成 `[256, 64]`，模型自动变为两层。

## 7. 设计原则与最佳实践

### 7.1 核心原则

| 原则 | 含义 | 反例 |
|---|---|---|
| **单一职责** | 一个块只做一件事 | 不要把预处理和推理放在同一个 forward |
| **最小接口** | 只暴露必要的参数 | `__init__` 只收 `in_dim, out_dim`，不暴露内部层 |
| **可组合性** | 块能嵌套到 `Sequential` 中 | 输出维度 = 下一个块的输入维度 |
| **无副作用** | `forward` 不应修改输入 | 不要在 forward 中 `X += something` |

### 7.2 工程化实践清单

1. **配置驱动**：所有超参集中管理，调参只改一处
2. **工厂函数**：统一的构建入口，保证 K 折评估和全量训练用相同架构
3. **权重初始化**：用 `self.apply(_init_weights)` 递归初始化，不要遗漏子模块
4. **注册表模式**：用字典映射字符串到类/函数，避免 if-else 蔓延

### 7.3 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 在 `forward` 里创建层 | 每次前向新建参数，之前学到的丢失 | 层永远在 `__init__` 中创建 |
| 忘记 `super().__init__()` | 参数注册机制失效，`.parameters()` 为空 | 第一行必须写 |
| 用 Python list 存子模块 | PyTorch 不会自动追踪列表中的模块 | 用 `nn.ModuleList` 或 `nn.Sequential` |
| 直接调 `net.forward(X)` | 绕过 `__call__` 的钩子机制 | 始终用 `net(X)` |

## 8. 常见的层与块组合模式

### 模式 1：MLP 标准块（表格数据）

```
Linear → BatchNorm → ReLU → Dropout
```

适用于结构化/表格数据的回归和分类任务（如 Kaggle 房价预测）。

### 模式 2：残差块（ResNet 风格）

```
X ──▶ [Conv → BN → ReLU → Conv → BN] ──▶ + ──▶ ReLU ──▶
 │                                          ↑
 └──────────────────────────────────────────┘
```

通过"跳跃连接"解决深层网络的梯度消失问题。

### 模式 3：编码器-解码器（Seq2Seq / U-Net）

```
编码器：逐步压缩 → 提取关键特征
解码器：逐步恢复 → 生成目标输出
跳跃连接：编码器特征直接传给解码器
```

### 模式 4：嵌套组合（多任务 / 复杂架构）

不同架构风格的块像乐高一样插在一起：

```python
chimera = nn.Sequential(NestMLP(), nn.Linear(16, 20), FixedHiddenMLP())
```

## 最小可运行代码

```python
import torch
from torch import nn
from torch.nn import functional as F

# 基本自定义块
class MLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.hidden = nn.Linear(20, 256)
        self.out = nn.Linear(256, 10)
    def forward(self, X):
        return self.out(F.relu(self.hidden(X)))

# 含高级技巧的块
class FixedHiddenMLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.rand_weight = torch.rand((20, 20), requires_grad=False)  # 常量
        self.linear = nn.Linear(20, 20)   # 被共享的层
    def forward(self, X):
        X = self.linear(X)
        X = F.relu(torch.mm(X, self.rand_weight) + 1)
        X = self.linear(X)                # 参数共享
        while X.abs().sum() > 1:          # 控制流
            X /= 2
        return X.sum()

# 嵌套组合
class NestMLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(20, 64), nn.ReLU(),
                                 nn.Linear(64, 32), nn.ReLU())
        self.linear = nn.Linear(32, 16)
    def forward(self, X):
        return self.linear(self.net(X))

chimera = nn.Sequential(NestMLP(), nn.Linear(16, 20), FixedHiddenMLP())
chimera(torch.rand(2, 20))
```

## 易错点

- 忘记 `super().__init__()` → 参数无法注册。
- 直接调用 `net.forward(X)` 而非 `net(X)`，绕过钩子机制。
- 把可学习参数写成普通张量（未用 `nn.Parameter`/子模块）→ 不被优化器追踪。
- 用 Python list 存子模块 → 用 `nn.ModuleList` 或 `nn.Sequential` 代替。
- 在 `forward` 中创建层 → 层永远写在 `__init__` 里。

## 复习卡片

**基础**
- Q: 自定义块要实现哪两个方法？
  A: `__init__`（注册子模块）和 `forward`（前向）。
- Q: 为什么用 `net(X)` 而不是 `net.forward(X)`？
  A: `__call__` 会触发注册的钩子等机制。
- Q: 子模块参数如何被追踪？
  A: 赋值给 `self.xxx` 后自动注册到父 Module。

**进阶**
- Q: `nn.Sequential` 的底层机制是什么？
  A: 内部维护一个 `OrderedDict`（`_modules`），按顺序遍历子模块执行。
- Q: 参数共享如何实现？
  A: 在 `forward` 中多次调用同一个子模块，梯度会自动累加。
- Q: forward 里能写 Python 控制流吗？
  A: 可以，PyTorch 是动态计算图，按实际执行的操作构建图。
- Q: 如何实现"改结构不改代码"？
  A: 用 Config 驱动，hidden_dims 列表通过循环自动搭建对应层数。
